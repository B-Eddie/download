# GDownload
Quickly download brightspace files, google docs, and slides

## The Problem
Saving teacher's lesson from brightspace takes way too long. Doing it manually reqeuires opening the file in a new tab, clicking the file button on the menu, clicking download, choosing options, and doing all these steps for every single file. This extension automates this so all this can be done in a few seconds rather than a lot of minutes.

## The Future
Supporting more websites to download from.

## Features
- Choosing which tabs to download from
- Choosing what format to download with
